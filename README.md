# StarDork

Steer your ship through a field of stars and probe the wormholes. Every
wormhole you probe brings more stars. Reach level 30 to win.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install stardork
av play stardork
```

## Keys

- Move: arrow keys, Home, PgUp, End, PgDn, or 1 to 9 on the number keys
- Fire a probe: `a` left, `s` up, `d` down, `f` right, `z` up-left,
  `x` up-right, `c` down-left, `v` down-right
- Quit: `q`, Esc or Ctrl+C
